# Feedback & Communication Audit (`docs/feedback-audit.md`)

This document inventories every interactive surface, overlay, user-triggered function, and async data-fetching path in the ASTD Value List codebase, evaluating each against the **Before (Anticipation) / During (Acknowledgement) / After (Resolution) / Error / Empty** communication model and `AGENTS.md` Web Interface Guidelines.

## 4. Summary of Highest-Priority Gaps

1. **Toast System (`useToastStore` + `GlobalToastContainer`) & Fragmented Local Toasts**:
   - `useToastStore` lacks action buttons (`Undo`, `Retry`), loading-to-success/error state updates, deduplication, max stack size, and pause-on-hover, and uses `transition: all` in inline styles.
   - Four different places (`App.tsx` trade toast, `useInventoryManager.ts`, `useAdminIntel.ts`, `useToastStore.ts`) manage separate toast states.
2. **Skeleton Flicker (`useShowDelay`)**:
   - `useShowDelay` does not take `isLoading` or enforce a minimum visible time (`~350ms`) after the initial show-delay (`~180ms`).
3. **Sync Visibility & Offline Queue Reliability (`UnitContext`, `SyncBanner`, `useNetworkSync`)**:
   - `UnitContext` doesn't expose `isFetching`, `dataUpdatedAt`, or `refetch` to the UI. `SyncBanner` has no **Retry** button.
   - `useNetworkSync` drops failed items from IndexedDB without retrying or alerting the user.
4. **Silent Failures & Dead-End Empty States**:
   - `MiniProfilePopout` hangs forever on skeleton if `fetchProfile` fails.
   - `NotificationsChannel` shows `"No notifications yet."` when logged out instead of a Login CTA, and uses a spinner instead of a layout-matching skeleton.
   - `MainCanvas` and `ExtraNoticesChannel` empty search states have no **"Reset Filters"** button.
   - Voting on ads/comments or pressing `Space` (Add to Vault) in `CommandPalette` while logged out does nothing silently instead of prompting the user to sign in.
5. **`AGENTS.md` & Accessibility Compliance**:
   - Virtualized rows in `MainCanvas/index.tsx` wrap every row in Framer Motion `<motion.div whileInView={...}>`.
   - Several icon-only buttons in `TopBar`, `MainCanvas`, `TradeAnalyzer`, `TradingAdsChannel`, and `NotificationsChannel` are missing `aria-label`.
   - `AdComposerModal` still has `backdrop-blur-sm` on its backdrop, and `TradeAnalyzer` / `TradingAdsChannel` / `AdInteractionModal` / `SmartParserMenu` still import a few `lucide-react` icons.
